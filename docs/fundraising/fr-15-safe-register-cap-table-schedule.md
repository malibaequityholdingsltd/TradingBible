> **Internal control record.** This register is not evidence that any SAFE has been issued. It is a schedule for recording SAFEs after the board authorizes the offering and each closing is completed. It must reconcile to the executed SAFEs and the cap table.

## 1. Purpose

The SAFE register is the company’s controlled record of each SAFE issued in the round. It supports:

- board and investor reporting;
- cap-table reconciliation;
- conversion calculations in a future Equity Financing;
- pro rata rights and transfer restrictions;
- Form D and state filing preparation; and
- audit and counsel review.

## 2. Register fields

Each SAFE must be recorded with the following fields:

| Field | Description |
|---|---|
| Register ID | Sequential identifier (for example, SAFE-2026-001) |
| Investor legal name | Exact legal name from the executed SAFE |
| Investor email | Verified email used for DocuSign and notices |
| Investor jurisdiction | Residence or organization jurisdiction |
| Eligibility basis | Accredited investor or Regulation S |
| Purchase Amount | Amount received in US$ |
| Valuation Cap | Post-money valuation cap |
| Discount | None |
| Pro rata rights | Yes / No and threshold |
| SAFE date | Date signed by the investor |
| Company signature date | Date countersigned |
| DocuSign envelope ID | Envelope identifier |
| Certificate of completion location | Controlled storage reference |
| Funds received date | Date cleared funds confirmed |
| Funding reference | Bank reference or ledger entry |
| Closing date | Date the closing conditions were satisfied |
| Conversion status | Not converted / converted / terminated |
| Conversion shares | Number, if converted |
| Transfer restrictions | Yes / No and notes |
| Amendments | Date and description |
| Notes | Any exception or open item |

## 5. Reconciliation controls

1. The register must reconcile to the executed SAFEs and the bank records at each closing.
2. No SAFE may be recorded without an executed copy and a completed eligibility certificate.
3. No cap-table entry may be made without board approval and a register entry.
4. Any amendment, waiver, transfer or conversion must be recorded within two business days.
5. The chief executive officer must review the register monthly and certify the reconciliation to the board quarterly.
6. Access to the register must be limited to the chief executive officer, the designated finance owner and counsel.
