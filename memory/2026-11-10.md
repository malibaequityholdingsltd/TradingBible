# 2026-11-10

## Auth and careers form fixes

- Phone country selector no longer snaps back to `US/CA +1` when no local digits are typed. `PhoneField` keeps the chosen dial code in local state and only derives the code from the full value after digits exist.
- Root cause of the dead “Send one-time code” button: `ButtonBase` forced every rendered `<button>` to `type="button"`. A click never submitted the form, while the Return key did.
- `GoldButton`/`GhostButton` now default to `type="submit"` when no `onClick` handler is supplied; explicit click actions remain `type="button"`.
- Explicit `type="submit"` added to the login, signup and careers actions.
- Careers application now shows a clear error if name or email is missing instead of silently doing nothing.
